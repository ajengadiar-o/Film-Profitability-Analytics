# Film Profitability Analytics

## Project Overview

This project explores film profitability using Microsoft Excel to understand how financial performance varies across film genres, studios, audience ratings, and release years.

The analysis uses structured summaries and visualizations to compare profitability patterns, identify high-performing segments, and support data-driven evaluation of film performance.

## Business Objectives

- Compare profitability across film genres and studios.
- Examine yearly performance trends.
- Explore the relationship between audience ratings and film profitability.
- Identify high-performing segments that may provide useful insights for strategic evaluation.

## Tools & Methods

**Primary Tool:** Microsoft Excel

- Data exploration and preparation
- Profitability analysis
- Genre and studio comparisons
- Audience rating analysis
- Yearly trend analysis
- PivotTables and data summarization
- Dashboard development and data visualization

## Key Insights

- Comedy contributed approximately 55.4% of the total profit in the analyzed dataset, followed by Romance at 20.3% and Drama at 17.6%.
- Profit contributions differed across studios, highlighting the importance of comparing performance at both genre and studio levels.
- Examining audience ratings alongside profitability provides additional context for evaluating film performance.

## Business Recommendations

- Use genre-level profitability comparisons to identify segments that contribute substantially to overall profit.
- Evaluate studio performance alongside genre mix and yearly trends before making strategic decisions.
- Consider audience ratings as one supporting indicator when evaluating film performance, rather than treating ratings alone as a measure of profitability.
- Use consistent performance reports to compare film profitability across genres, studios, and years.

## Conclusion

This project demonstrates how Microsoft Excel can be used to evaluate profitability patterns across the film industry. By comparing genres, studios, audience ratings, and yearly performance, the analysis provides a structured foundation for understanding differences in film profitability.
